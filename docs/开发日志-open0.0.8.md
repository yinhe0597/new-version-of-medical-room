# 开发日志 - open0.0.8（2026-05-18）

## 本次变更

### 💊 医生端用法选项扩展

**涉及文件：**
- `frontend/src/views/doctor/VisitForm.vue`（接诊开方页面）
- `frontend/src/views/doctor/DirectPurchase.vue`（单独购药页面）

**变更内容：**

在处方用法（usageOptions）下拉菜单中新增以下选项：
- 冲泡
- 嚼服
- 冲服
- 舌下含服

**变更前（DirectPurchase.vue）：**
```
'--', '口服', '外用', '静脉注射', '肌肉注射', '皮下注射', '雾化吸入', '含服', '外敷', '滴眼', '滴耳', '滴鼻'
```

**变更后（两个文件统一）：**
```
'--', '口服', '嚼服', '冲泡', '冲服', '舌下含服', '外用', '静脉注射', '静脉滴注', '肌肉注射', '皮下注射', '雾化吸入', '含服', '外敷', '滴眼', '滴耳', '滴鼻'
```

> 注：VisitForm.vue 比 DirectPurchase.vue 多一个"静脉滴注"选项（配合静脉给药配伍功能）。

**目的：** 满足临床用药场景需求，冲泡适用于颗粒剂/茶剂，嚼服适用于咀嚼片，舌下含服适用于硝酸甘油等需舌下快速吸收的药物。
