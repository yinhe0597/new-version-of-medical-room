# 开发日志 v26.05.07.14.05（2026-05-07）

## 本次更新概述

修复管理员端药品出库报表时间显示问题（UTC→本地时间），以及护士端库存盘点页面添加翻页功能。

---

## 一、修复：出库报表出库时间显示不正确

### 问题现象

药品出库报表中明细数据的出库时间显示不正确，显示的是 UTC 时间而非本地时间（中国标准时间 CST，UTC+8）。

### 根因分析

`Payment.payment_date` 字段使用 `datetime.utcnow()` 存储 UTC 时间，在出库报表明细接口和导出接口中，直接对该字段做 `strftime` 格式化输出，未做时区转换，导致显示时间比实际早 8 小时。

### 修复方案

在 `backend/app/api/admin.py` 中，药品出库报表明细接口和导出接口的 `payment_date` 格式化前，加上 `timedelta(hours=8)` 转为中国标准时间：

```python
# 修复前
'payment_date': item.payment_date.strftime('%Y-%m-%d %H:%M:%S') if item.payment_date else ''

# 修复后
'payment_date': (item.payment_date + timedelta(hours=8)).strftime('%Y-%m-%d %H:%M:%S') if item.payment_date else ''
```

## 二、修复：护士端库存盘点页面无翻页功能

### 问题现象

护士端"库存与入库"功能的"库存盘点"页面没有翻页功能，药品列表只显示前 50 条，无法浏览全部药品。

### 修复方案

#### 1. 后端（nurse.py）

`/nurse/drugs` 接口从 `limit(50)` 改为 `paginate()` 分页查询，添加 `page` 和 `size` 参数，返回 `meta` 分页信息：

```python
# 修复前
drugs = query.limit(50).all()

# 修复后
page = request.args.get('page', 1, type=int)
size = request.args.get('size', 20, type=int)
pagination = query.paginate(page=page, per_page=size, error_out=False)
```

返回结构新增 `meta` 字段：

```json
{
  "drugs": [...],
  "meta": {
    "page": 1,
    "size": 20,
    "total": 125,
    "pages": 7
  }
}
```

#### 2. 前端（Inventory.vue）

添加 `el-pagination` 分页组件，每页 20 条，支持翻页浏览全部药品。
