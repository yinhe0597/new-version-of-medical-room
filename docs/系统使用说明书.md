# 校医务室诊疗管理系统 V1.08 系统使用说明书

更新时间：2026-03-27

## 1. 系统登录

- 浏览器访问：`http://127.0.0.1:5888`
- 初始账号（密码由部署人员配置或首次启动随机生成）
  - 管理员：`admin`
  - 医生：`doctor`
  - 护士：`nurse`
- 首次密码见部署控制台；登录后必须立即修改，密码至少 12 位
- 医生、护士、财务从侧边栏“账号设置”修改密码；管理员从“系统设置”修改，成功后需重新登录

## 2. 医生端功能

- 患者搜索：支持学号/姓名检索，未检索到可新建档案
- 接诊开方：录入病历信息、诊断与处方（用法/用量/频次/时间/天数），支持医生建议
- 处方历史：查看本人历史处方，支持按日期筛选

## 3. 护士端功能

- 待处理处方：查看待缴费/待执行处方
- 执行处方：完成扣减库存与结算相关流程
- 库存查看：查询当前库存与预警信息

## 4. 管理员端功能

- 用户管理：维护医生/护士/财务账号，支持重置密码和启用/停用；停用不会删除历史业务归属
- 药品管理：维护药品字典与库存，支持批量导入/更新
- 统计报表：按时间范围导出就诊病历与相关明细
- 数据备份：通过“系统设置”定期下载备份；SQLite 导出 `.db`，MySQL 导出 `.sql`
