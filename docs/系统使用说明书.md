# 校医务室诊疗管理系统 V1.08 系统使用说明书

更新时间：2026-03-27

## 1. 系统登录

- 浏览器访问：`http://127.0.0.1:5888`
- 初始账号（密码均为 `123456`）
  - 管理员：`admin`
  - 医生：`doctor`
  - 护士：`nurse`

## 2. 医生端功能

- 患者搜索：支持学号/姓名检索，未检索到可新建档案
- 接诊开方：录入病历信息、诊断与处方（用法/用量/频次/时间/天数），支持医生建议
- 处方历史：查看本人历史处方，支持按日期筛选

## 3. 护士端功能

- 待处理处方：查看待缴费/待执行处方
- 执行处方：完成扣减库存与结算相关流程
- 库存查看：查询当前库存与预警信息

## 4. 管理员端功能

- 用户管理：维护医生/护士账号，支持重置密码
- 药品管理：维护药品字典与库存，支持批量导入/更新
- 统计报表：按时间范围导出就诊病历与相关明细
- 数据备份：建议定期备份 `backend/app.db`
