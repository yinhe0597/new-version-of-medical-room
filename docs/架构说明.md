# 校医务室诊疗管理系统（CMIS）架构说明

## 1. 总体架构

- 架构形态：前后端分离 B/S
- 前端：Vue 3 + Vite + Pinia + Element Plus（[frontend](file:///workspace/medical-room-management-system/frontend)）
- 后端：Flask + Flask-SQLAlchemy + Flask-Migrate + Flask-JWT-Extended（[backend](file:///workspace/medical-room-management-system/backend)）
- 数据库：SQLite（默认文件 `data/app.db`），可通过 `DATABASE_URL` 切换 MySQL（[config.py](file:///workspace/medical-room-management-system/backend/config.py)）
- API 前缀：`/api`（蓝图挂载见 [create_app](file:///workspace/medical-room-management-system/backend/app/__init__.py#L10-L28)）

## 2. 角色与边界

- 医生（doctor）：患者检索/建档、接诊开方、查看本人历史处方与详情
- 护士（nurse）：待处置处方、处方执行（扣减库存 + 结算）、库存调整与盘点记录
- 管理员（admin）：药品字典/库存维护、批量导入、智能盘库、营收统计、账号管理、数据库备份

## 3. 认证与鉴权

- 登录接口：`POST /api/auth/login`，成功返回 JWT access_token（[auth.py](file:///workspace/medical-room-management-system/backend/app/api/auth.py)）
- 前端持久化：token/user 写入 localStorage（[user store](file:///workspace/medical-room-management-system/frontend/src/store/user.js)）
- 请求加签：Axios 请求拦截器自动加 `Authorization: Bearer <token>`（[request.js](file:///workspace/medical-room-management-system/frontend/src/api/request.js#L8-L16)）
- 角色鉴权：后端 `role_required(...)` 装饰器校验 token + 查询 `User.role`（[decorators.py](file:///workspace/medical-room-management-system/backend/app/utils/decorators.py#L6-L25)）
- 路由守卫：前端按 `route.meta.role` 限制页面访问（[router guard](file:///workspace/medical-room-management-system/frontend/src/router/index.js#L107-L133)）

## 4. 核心业务闭环

### 4.1 接诊开方（医生）

- 患者检索：`GET /api/doctor/patient/search`
- 未命中建档：`POST /api/doctor/patient`
- 开立就诊 + 处方明细：`POST /api/doctor/visits`
  - 计算总金额：诊察费 + 明细金额
  - 校验库存（仅 `Drug.type == 1` 的药品参与库存校验）
  - 支持整装/散装：`has_scattered/scattered_price/conversion_rate`

### 4.2 处方执行与结算（护士）

- 待处理列表：`GET /api/nurse/pending-visits`
- 处方详情：`GET /api/nurse/visits/<visit_id>`
- 执行（事务）：`POST /api/nurse/visits/<visit_id>/execute`
  - 二次校验库存
  - 扣减库存（散装按 `conversion_rate` 折算，向上取整）
  - 生成 `Payment`，并将 `Visit.status` 置为 `completed`
- 票据状态：`PUT /api/nurse/payments/<payment_id>/print`

### 4.3 字典维护与报表（管理员）

- 药品维护：CRUD + 停用/启用
- 批量导入：CSV/Excel（支持合并同名同规格）
- 智能盘库：合并重复药品并迁移处方引用，返回低库存预警
- 统计：`/api/admin/statistics/revenue` 汇总营收/成本/利润并返回明细
- 备份：`GET /api/admin/backup` 根据当前数据库下载 SQLite `.db`，或包含 SQL 与校验 manifest 的 MySQL `.zip`

## 5. 数据模型（关键表）

模型集中在 [models/__init__.py](file:///workspace/medical-room-management-system/backend/app/models/__init__.py)。

- User：账号（username/password_hash/real_name/role）
- Patient：患者（student_id/name/gender/grade/college/major/class_name/phone + name_pinyin/name_initials）
- Drug：药品/项目（type/price/stock/status + purchase_price/has_scattered/scattered_price/conversion_rate + batch_no/inbound_at）
- Visit：就诊（病历字段、diagnosis、doctor_advice、consultation_fee、total_amount、status）
- PrescriptionItem：处方明细（usage/dosage/frequency/timing/days/quantity/price_at_visit/amount + is_scattered/purchase_cost）
- Payment：支付（visit_id UNIQUE、nurse_id、amount、payment_method、receipt_printed）
- InventoryRecord：库存调整流水（drug_id/nurse_id/old_stock/new_stock/remark/timestamp）
- DiagnosisDict：诊断字典（code/name/pinyin）

## 6. 运行方式（开发）

### 6.1 后端

```bash
cd backend
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python init_db.py
.venv/bin/python run.py
```

### 6.2 前端

```bash
cd frontend
npm install
npm run dev
```

访问：`http://localhost:5888`
