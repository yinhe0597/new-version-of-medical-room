# 校医务室诊疗管理系统 V1.08 部署与维护说明

更新时间：2026-03-27

## 1. 系统简介

- 架构：前后端分离（Vue 3 + Flask）
- 数据库：MySQL (医务室专用账号 `yiwushi`)
- 端口：
  - 前端：5888
  - 后端：5000
  - 数据库：3306

## 2. 数据库部署前置操作（必做）

在项目编译后的部署前，请教用户先打开 MySQL（例如使用 Navicat、DBeaver 或命令行），并执行以下操作：

1. **创建医务室专用的用户和密码**
   统一设置为：
   - 账号：`yiwushi`
   - 密码：`xibokeladi`
   - 默认端口：`3306`

2. **运行数据库建库脚本**
   请找到项目根目录下的 `init_database.sql` 脚本（提前准备好）。在 MySQL 中运行该脚本，它会自动创建 `medical_db` 数据库并赋予 `yiwushi` 账号权限。

   *这样一来可以在部署的时候比较丝滑，也便于后期维护。*

## 3. 开发环境快速启动（Windows）

- 一键启动：运行项目根目录的 `start_dev.bat`
- 手动启动
  - 后端：进入 `backend/`，安装依赖后运行 `python run.py`
  - 前端：进入 `frontend/`，安装依赖后运行 `npm run dev`

## 4. 生产部署建议（Windows Server）

- 后端：推荐使用 `waitress` 部署 Flask
- 前端：构建生成 `frontend/dist/` 后由 Nginx/IIS 托管，并代理 `/api` 到后端
- 数据备份：定期在后台使用“一键备份数据”导出 `.sql` 文件，或者使用定时任务备份 MySQL `medical_db`

## 5. 常见维护事项

- 初次上线后请立即修改默认账号密码
- 升级前先备份数据库，再替换程序文件
- 如遇异常日志或启动失败，优先检查端口占用与依赖完整性
