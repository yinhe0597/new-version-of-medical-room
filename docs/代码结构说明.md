# 校医务室管理系统 - 代码结构说明

本文档详细描述本项目的目录结构与核心文件的职责，旨在帮助二次开发人员快速熟悉代码分布和业务模块所在位置。

## 1. 根目录概览

```text
medical-room-management-system/
├── backend/                  # 后端 Flask 项目目录（Python代码）
├── frontend/                 # 前端 Vue 3 项目目录（Node/JS代码）
├── docs/                     # 项目文档目录（部署、架构、开发指南等）
├── init_database.sql         # 数据库初始化脚本（创建用户及数据库）
└── README.md                 # 项目根入口说明
```

## 2. 后端代码结构 (`backend/`)

后端采用 Flask 工厂模式和蓝图（Blueprints）组织代码。

```text
backend/
├── app/                      # 核心应用包
│   ├── __init__.py           # Flask App 工厂函数、SQLAlchemy 实例初始化
│   ├── models/               # 数据库 ORM 模型目录
│   │   └── __init__.py       # 定义了 User, Patient, Drug, Visit, PrescriptionItem, Payment, InventoryRecord 及 DiagnosisDict 等所有核心模型
│   ├── api/                  # API 蓝图目录（按角色划分路由）
│   │   ├── __init__.py       # Blueprint 注册点 (`bp`)
│   │   ├── admin.py          # 管理员接口（药品管理、用户管理、系统设置、备份、学生导入）
│   │   ├── auth.py           # 登录鉴权接口（生成 JWT token）
│   │   ├── doctor.py         # 医生接口（患者搜索、开处方、病历查询）
│   │   └── nurse.py          # 护士接口（待处理处方、处方审核/驳回、改价、库存扣减、收费）
│   └── utils/                # 工具函数目录
│       └── decorators.py     # 自定义装饰器（如 `@role_required` 权限控制）
│
├── migrations/               # Alembic 数据库迁移文件存放目录（由 flask-migrate 生成）
│   ├── env.py                # 迁移环境配置
│   └── versions/             # 各个版本的迁移脚本（如新增字段、表结构修改）
│
├── tests/                    # 单元测试目录（TDD 开发模式）
│   ├── test_auth_login.py    # 登录测试
│   ├── test_init_db.py       # 初始化建库与种子数据测试
│   ├── test_nurse_visit_workflow.py # 护士审核、驳回、改价、执行工作流的完整测试
│   └── ...                   # 其他测试用例
│
├── config.py                 # 全局配置文件（定义数据库连接 `SQLALCHEMY_DATABASE_URI` 等）
├── init_db.py                # 快速建库与插入演示数据脚本（admin/doctor/nurse 等）
├── import_icd10.py           # ICD-10 疾病诊断字典导入脚本
├── reset_default_passwords.py# 密码重置紧急工具脚本
├── run.py                    # 后端开发服务器启动入口
└── requirements.txt          # Python 依赖清单
```

## 4. 核心数据模型说明

理解后端模型（`backend/app/models/__init__.py`）是二次开发的关键：

- `User`：系统账号（包含 `admin`, `doctor`, `nurse` 三种角色）。
- `Patient`：患者（学生/教职工）档案，包含学号（`student_id`）、姓名、班级等。
- `Visit`：就诊记录（核心表），关联医生与患者。记录了病历信息和处方状态（`pending` 待审核, `nurse_verified` 护士已审核, `rejected` 护士已驳回, `completed` 已执行收费）。
- `PrescriptionItem`：处方明细表，关联 `Visit` 和 `Drug`。记录了用法用量、数量、单价（`price_at_visit`）、并且支持**护士改价留痕**（`new_price` 等审计字段）。
- `Payment`：支付记录，当护士成功执行处方（`completed`）后生成。
- `Drug`：药品及收费项目字典/库存表。
- `InventoryRecord`：出入库明细记录，供盘点使用。
- `DiagnosisDict`：ICD-10 疾病诊断字典，供医生开方时快速检索。
