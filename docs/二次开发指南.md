# 校医务室管理系统 - 二次开发指南

本文档专为后续接手本项目的开发人员（二次开发人员）编写，包含项目技术栈说明、开发环境搭建、常见开发任务（如新增接口、修改数据库）的标准流程。

## 1. 技术栈说明

本系统采用经典的“前后端分离”架构。

### 1.1 后端技术栈
- **语言**：Python 3.8+ (推荐 Python 3.10+)
- **Web 框架**：Flask (轻量级、灵活)
- **数据库 ORM**：Flask-SQLAlchemy (基于 SQLAlchemy)
- **数据库迁移**：Flask-Migrate (基于 Alembic)
- **认证授权**：Flask-JWT-Extended (JWT Token 机制)
- **数据库引擎**：SQLite（默认）/ MySQL（可选，通过 `pymysql` 驱动连接）

### 1.2 前端技术栈
- **核心框架**：Vue 3 (Composition API / `<script setup>` 语法)
- **构建工具**：Vite (极速的本地开发与构建)
- **UI 组件库**：Element Plus
- **状态管理**：Pinia
- **路由管理**：Vue Router 4
- **网络请求**：Axios

## 2. 本地开发环境搭建流程

### 2.1 数据库准备（SQLite 默认，MySQL 可选）

- 默认无需安装数据库服务，初始化后使用项目根目录的 `data/app.db`。
- 需要接入 MySQL 时，再启动 MySQL 5.7/8.0+，执行根目录 `init_database.sql` 创建数据库，
  使用部署环境自己的强密码创建最小权限业务账号，并通过 `DATABASE_URL` 配置连接。
  仓库不提供或保存共享数据库密码，配置示例见根目录 `.env.example`。

### 2.2 后端服务启动
1. 进入 `backend/` 目录。
2. 创建并激活虚拟环境：
   ```bash
   python -m venv .venv
   # Windows: .venv\Scripts\activate
   # Linux/Mac: source .venv/bin/activate
   ```
3. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
4. 数据库结构与种子数据初始化：
   ```bash
   python init_db.py
   ```
   *(如果需要导入 ICD-10 字典表，请确保相应的 Excel 文件在正确路径，并执行 `python import_icd10.py`)*
5. 启动 Flask 服务：
   ```bash
   python run.py
   ```
   *(服务默认运行在 `http://127.0.0.1:5000`)*

### 2.3 前端服务启动
1. 进入 `frontend/` 目录。
2. 安装依赖：
   ```bash
   npm install
   # 或使用 pnpm install / yarn install
   ```
3. 启动开发服务器：
   ```bash
   npm run dev
   ```
   *(服务默认运行在 `http://localhost:5888`，并在 `vite.config.js` 中配置了对 `/api` 到 `http://127.0.0.1:5000` 的代理)*

## 3. 常见开发任务规范

### 3.1 如何修改数据库结构？
本项目使用 Flask-Migrate 管理正式迁移，同时由应用工厂的 `_sync_model_schema()`
为历史 SQLite/MySQL 数据库幂等补齐缺失表、可空字段和索引。新增非空字段、字段改型、
约束或数据回填仍必须编写并审查 Alembic migration，不能只依赖运行时同步。

1. 确保在 `backend/` 目录下，且虚拟环境已激活。
2. 生成迁移脚本：
   ```bash
   flask db migrate -m "添加了某某字段"
   ```
3. 检查 `backend/migrations/versions/` 下新生成的 Python 脚本，确认 `upgrade()` 和 `downgrade()` 逻辑正确。
4. 将变更应用到数据库：
   ```bash
   flask db upgrade
   ```
*(注意：如果多人协同开发，合并代码后也需要运行 `flask db upgrade` 来同步他人的数据库变更)*

### 3.2 如何新增一个后端接口？
1. **定义路由**：在 `backend/app/api/` 下找到对应的角色模块（如 `admin.py`, `doctor.py`, `nurse.py`）或新建模块。
2. **编写视图函数**：
   ```python
   from flask import request, jsonify
   from backend.app.api import bp
   from backend.app.utils.decorators import role_required

   @bp.route('/admin/new_feature', methods=['GET'])
   @role_required('admin')  # 权限控制：仅管理员可访问
   def new_feature():
       # 业务逻辑
       return jsonify({"msg": "success", "data": []}), 200
   ```
3. **参数校验与数据库操作**：通过 `request.get_json()` 或 `request.args` 获取参数。修改数据库后必须 `db.session.commit()`，如遇异常请 `db.session.rollback()`。

### 3.3 如何新增一个前端页面？
1. **创建 Vue 组件**：在 `frontend/src/views/` 对应的角色文件夹（如 `admin/`）下创建 `YourPage.vue`。
2. **配置路由**：打开 `frontend/src/router/index.js`，在对应的父级路由（如 `AdminDashboard` 的 `children` 数组）中注册新页面。
3. **增加菜单入口**：打开对应的 Dashboard 组件（如 `frontend/src/views/admin/Dashboard.vue`），在 `<el-menu>` 中添加对应的 `<el-menu-item>`。
4. **接口请求**：在 Vue 组件中引入封装好的 `request`：
   ```javascript
   import request from '@/api/request'
   
   const fetchData = async () => {
     try {
       const res = await request.get('/admin/new_feature')
       // 处理响应数据
     } catch (error) {
       ElMessage.error('获取数据失败')
     }
   }
   ```

## 4. 自动化测试

后端核心业务逻辑（尤其是状态流转、金额计算、权限控制等）必须包含单元测试。
- 测试目录：`backend/tests/`
- 运行测试：
  ```bash
  cd backend
  python -m unittest discover -s tests -p 'test_*.py'
  ```
- **开发原则（TDD 推荐）**：在修复 Bug 或增加影响金额/库存的核心逻辑时，请先在 `tests/` 中编写预期行为的测试用例，再修改业务代码直到测试通过。

## 5. 项目交接与代码规范
- 代码中涉及金额计算的地方，请务必保证前后端逻辑一致，且最终以**后端计算为准**。
- 日期时间统一使用 UTC 存储；模型默认值使用 `backend.app.models.utcnow()`，避免继续引入已弃用的 `datetime.utcnow()`，前端展示时按本地时区格式化。
- 修改代码后，务必更新 `docs/接口清单.md` 与 `docs/架构说明.md`。
