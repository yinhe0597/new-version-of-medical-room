# 开发日志 v26.05.08.08.16

## 修改日期
2026-05-08

## 修改内容

### 1. 新增运营日志系统

- 新增 `OperationLog` 数据模型，用于记录关键运营事件
- 记录三类事件：
  - 医生修改病例（action_type='visit_edit'）
  - 管理员/护士新增药品种类（action_type='drug_create'）
  - 临时人员就诊（action_type='temp_patient_visit'）
- 管理员端新增"运营日志"页面（/admin/operation-log），支持按操作类型和日期筛选，可展开查看变更详情

### 2. 医生端病例修改功能优化

- 将"补充病历"改为"修改病历"，医生可对所有未驳回的就诊记录随时修改病历
- 去除原有"病历为空才能补充"的限制条件
- 修改时自动预填当前已有病历内容
- 每次修改自动记录操作日志（修改人、时间、变更字段及前后值）

### 3. 病例修改历史追溯

- 新增 GET /doctor/visits/{id}/revisions 接口，查询就诊记录的修改历史
- 医生端"病例复盘"弹窗中新增"修改记录"区域，以时间线形式展示修改历史
- 支持查看每次修改的详细变更内容（哪个字段从什么改为什么）
