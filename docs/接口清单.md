# API 接口清单（main / open0.0.20 修复基线）

基础前缀：`/api`。除登录和示例首页外，接口均使用 JWT；角色以实际后端
`@role_required` 为准。更新时间：2026-07-13。

## 1. 公共与鉴权

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/` | 公开 | 示例响应 |
| GET | `/protected` | 登录 | JWT 示例 |
| GET | `/admin-only` | admin | 管理员权限示例 |
| GET | `/doctor-only` | doctor/admin | 医生权限示例 |
| GET | `/health/live` | 公开 | 进程存活探针，不访问数据库 |
| GET | `/health/ready` | 公开 | 数据库就绪探针；不可用时返回 503 |
| POST | `/auth/login` | 公开 | 登录，返回 token 和用户信息 |
| POST | `/auth/change-password` | 登录 | 修改当前用户密码（新密码至少 12 位，旧 token 立即失效） |

## 2. 医生端

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/doctor/patient/search` | 姓名/学号/手机号/拼音检索患者 |
| POST | `/doctor/patient` | 新建四类患者档案 |
| PUT | `/doctor/patient/<id>` | 更新患者联系方式、年龄、身份证 |
| GET | `/doctor/patient/<patient_id>/visits` | 患者全部就诊简表 |
| GET | `/doctor/drugs/search` | 搜索药品、项目、耗材及库存状态 |
| GET | `/doctor/diagnoses/search` | ICD-10/汉字/拼音诊断检索 |
| POST | `/doctor/visits` | 创建就诊和处方，执行金额与库存校验 |
| GET | `/doctor/visits/history` | 当前医生历史记录分页 |
| GET | `/doctor/visits/<visit_id>` | 就诊详情及状态时间线 |
| PUT | `/doctor/visits/<visit_id>/medical-record` | 补充/修改本人病历 |
| GET | `/doctor/visits/<visit_id>/revisions` | 病历修改记录（doctor/admin） |
| GET | `/doctor/templates` | 当前医生文本模板列表 |
| POST | `/doctor/templates` | 新建文本模板 |
| PUT | `/doctor/templates/<template_id>` | 更新文本模板 |
| DELETE | `/doctor/templates/<template_id>` | 删除文本模板 |
| POST | `/doctor/parked-visits` | 保存或更新挂单 |
| GET | `/doctor/parked-visits` | 当前医生挂单列表 |
| GET | `/doctor/parked-visits/<parked_id>` | 挂单详情 |
| DELETE | `/doctor/parked-visits/<parked_id>` | 删除挂单 |
| GET | `/doctor/patient/<patient_id>/parked-visit` | 查询患者当前挂单 |

## 4. 管理端与共享报表

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/admin/backup/mysql` | admin | MySQL SQL 下载兼容入口 |
| GET | `/admin/backup` | admin | 按当前数据库下载 `.db`/`.sql` |
| POST | `/admin/backup` | admin | 旧客户端 SQLite 服务端备份兼容入口 |
| GET | `/admin/patients/template` | admin | 四类患者 CSV 模板 |
| POST | `/admin/patients/import` | admin | 患者 CSV 批量导入 |
| GET | `/admin/patients` | admin | 患者分页搜索 |
| POST | `/admin/patients` | admin | 新建患者 |
| PUT | `/admin/patients/<id>` | admin | 更新患者 |
| DELETE | `/admin/patients/<id>` | admin | 删除无就诊引用患者 |
| GET | `/admin/patients/<id>/visits` | admin | 患者历史就诊 |
| GET | `/admin/visits/<visit_id>` | admin | 就诊详情 |
| GET | `/admin/drugs` | admin/nurse/finance | 物资分页；finance 只读 |
| POST | `/admin/drugs` | admin/nurse | 新建药品/项目/耗材 |
| PUT | `/admin/drugs/<id>` | admin/nurse | 更新、停用或启用 |
| POST | `/admin/drugs/<drug_id>/inbound` | admin/nurse | 普通非库存组物资补货 |
| DELETE | `/admin/drugs/<id>` | admin/nurse | 删除无引用、非库存组记录 |
| POST | `/admin/drugs/import` | admin/nurse | CSV 物资导入 |
| POST | `/admin/drugs/import_xls` | admin/nurse | Excel 物资导入 |
| GET | `/admin/drugs/template` | admin/nurse/finance | 下载物资导入模板 |
| POST | `/admin/drugs/smart-inventory` | admin/nurse | 扫描预警；确认参数后合并重复记录 |
| GET | `/admin/statistics/revenue` | admin/nurse/finance | 实收营收/成本/利润分页统计 |
| GET | `/admin/statistics/revenue/users` | admin/nurse/finance | 报表人员筛选项 |
| GET | `/admin/statistics/revenue/export` | admin/nurse/finance | 营收 Excel 导出 |
| GET | `/admin/statistics/drug-outbound` | admin/nurse/finance | 药品/耗材出库分页 |
| GET | `/admin/statistics/drug-outbound/export` | admin/nurse/finance | 出库 Excel 导出 |
| GET | `/admin/users` | admin | 用户列表 |
| POST | `/admin/users` | admin | 创建 doctor/nurse/finance |
| PUT | `/admin/users/<id>` | admin | 更新账号、角色、密码或重新启用 |
| DELETE | `/admin/users/<id>` | admin | 软停用非管理员账号并注销旧令牌 |
| GET | `/admin/operation-logs` | admin | 运营日志分页和筛选 |

`smart-inventory` 首次调用只返回 `merge_candidates` 和预警；确认时必须同时提交
`confirm_merge=true` 和首次响应中各组 `record_ids` 组成的 `merge_candidate_ids`。
候选发生变化时返回 409，要求重新预览。财务角色访问报表明细时，患者姓名脱敏，
学号、诊断和主诉不返回。

## 5. 财务端

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/finance/dashboard/summary` | admin/finance | 今日/本月营收、成本、利润、环比 |
| GET | `/finance/profit-trend` | admin/finance | 近 N 天营收成本利润趋势 |
| GET | `/finance/revenue/by-type` | admin/finance | 按实收拆分药品/项目/耗材/诊查费 |

财务端同时复用第 4 节标记为 `finance` 可访问的药品只读、营收和出库接口；
患者姓名在财务响应和导出中脱敏。
