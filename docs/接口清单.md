# 接口清单（全量）

基础前缀：`/api`

## 1. 公共

- `GET /`：健康检查/示例响应（[routes.py](file:///workspace/medical-room-management-system/backend/app/api/routes.py#L7-L9)）
- `GET /protected`：JWT 保护示例（[routes.py](file:///workspace/medical-room-management-system/backend/app/api/routes.py#L11-L16)）
- `GET /admin-only`：管理员示例（[routes.py](file:///workspace/medical-room-management-system/backend/app/api/routes.py#L18-L22)）
- `GET /doctor-only`：医生/管理员示例（[routes.py](file:///workspace/medical-room-management-system/backend/app/api/routes.py#L24-L28)）

## 2. 鉴权

- `POST /auth/login`：登录，返回 `{access_token, user}`（[auth.py](file:///workspace/medical-room-management-system/backend/app/api/auth.py#L6-L31)）

## 3. 医生端（role=doctor）

- `GET /doctor/patient/search`：患者搜索（keyword 支持学号片段、姓名、拼音首字母/全拼）（[doctor.search_patient](file:///workspace/medical-room-management-system/backend/app/api/doctor.py#L23-L84)）
- `POST /doctor/patient`：建档（最小字段：name/gender/phone；其他字段可选）（[doctor.create_patient](file:///workspace/medical-room-management-system/backend/app/api/doctor.py#L86-L108)）
- `PUT /doctor/patient/<id>`：更新患者（目前用于更新 phone）（[doctor.update_patient](file:///workspace/medical-room-management-system/backend/app/api/doctor.py#L109-L119)）
- `GET /doctor/patient/<patient_id>/visits`：就诊历史简表（[doctor.get_patient_history](file:///workspace/medical-room-management-system/backend/app/api/doctor.py#L121-L136)）
- `GET /doctor/drugs/search`：药品/项目搜索（[doctor.search_drugs](file:///workspace/medical-room-management-system/backend/app/api/doctor.py#L138-L165)）
- `GET /doctor/diagnoses/search`：诊断搜索（ICD/拼音/汉字）（[doctor.search_diagnoses](file:///workspace/medical-room-management-system/backend/app/api/doctor.py#L167-L246)）
- `POST /doctor/visits`：开立就诊 + 处方明细（库存校验/金额计算/整散装）（[doctor.create_visit](file:///workspace/medical-room-management-system/backend/app/api/doctor.py#L248-L342)）
- `GET /doctor/visits/history`：本人就诊列表（支持 start_date）（[doctor.get_visit_history](file:///workspace/medical-room-management-system/backend/app/api/doctor.py#L344-L382)）
- `GET /doctor/visits/<visit_id>`：就诊详情（限制本人访问）（[doctor.get_doctor_visit_detail](file:///workspace/medical-room-management-system/backend/app/api/doctor.py#L384-L438)）

## 4. 护士端（role=nurse）

- `GET /nurse/pending-visits`：待处置就诊列表（status=pending）（[nurse.get_pending_visits](file:///workspace/medical-room-management-system/backend/app/api/nurse.py#L10-L27)）
- `GET /nurse/visits/<visit_id>`：处方详情（含库存信息）（[nurse.get_visit_detail](file:///workspace/medical-room-management-system/backend/app/api/nurse.py#L92-L135)）
- `POST /nurse/visits/<visit_id>/execute`：执行处方（扣库 + 生成 Payment + 完成就诊）（[nurse.execute_visit](file:///workspace/medical-room-management-system/backend/app/api/nurse.py#L136-L186)）
- `PUT /nurse/payments/<payment_id>/print`：标记票据已打印（[nurse.mark_printed](file:///workspace/medical-room-management-system/backend/app/api/nurse.py#L187-L193)）
- `GET /nurse/drugs`：库存盘点列表（多条件过滤）（[nurse.list_drugs](file:///workspace/medical-room-management-system/backend/app/api/nurse.py#L195-L250)）
- `POST /nurse/inventory`：手工改库存并记录流水（[nurse.update_inventory](file:///workspace/medical-room-management-system/backend/app/api/nurse.py#L29-L60)）
- `GET /nurse/inventory/records`：库存流水分页查询（[nurse.get_inventory_records](file:///workspace/medical-room-management-system/backend/app/api/nurse.py#L61-L91)）

## 5. 管理端（role=admin）

### 5.1 药品字典/库存

- `GET /admin/drugs`：分页查询（[admin.get_drugs](file:///workspace/medical-room-management-system/backend/app/api/admin.py#L15-L55)）
- `POST /admin/drugs`：新增（[admin.create_drug](file:///workspace/medical-room-management-system/backend/app/api/admin.py#L56-L92)）
- `PUT /admin/drugs/<id>`：更新/停用/启用（[admin.update_drug](file:///workspace/medical-room-management-system/backend/app/api/admin.py#L93-L114)）
- `DELETE /admin/drugs/<id>`：彻底删除（若被处方引用会失败）（[admin.delete_drug](file:///workspace/medical-room-management-system/backend/app/api/admin.py#L116-L130)）
- `GET /admin/drugs/template`：下载 CSV 导入模板（[admin.get_drug_template](file:///workspace/medical-room-management-system/backend/app/api/admin.py#L316-L333)）
- `POST /admin/drugs/import`：CSV 导入/合并（[admin.import_drugs](file:///workspace/medical-room-management-system/backend/app/api/admin.py#L131-L220)）
- `POST /admin/drugs/import_xls`：Excel 导入（[admin.import_drugs_xls](file:///workspace/medical-room-management-system/backend/app/api/admin.py#L221-L315)）
- `POST /admin/drugs/smart-inventory`：智能盘库（合并重复/低库存预警）（[admin.smart_inventory](file:///workspace/medical-room-management-system/backend/app/api/admin.py#L335-L406)）

### 5.2 营收统计

- `GET /admin/statistics/revenue`：按日/月/年统计（含利润与明细）（[admin.get_revenue_stats](file:///workspace/medical-room-management-system/backend/app/api/admin.py#L407-L476)）

### 5.3 用户管理

- `GET /admin/users`：查询医生/护士账号（[admin.get_users](file:///workspace/medical-room-management-system/backend/app/api/admin.py#L477-L489)）
