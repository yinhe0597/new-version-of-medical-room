## 3. 按角色划分的功能清单

### 3.1 医生端（Doctor）

| 功能组 | 功能 | 页面/组件 | 对接 API | 业务规则 |
|--------|------|-----------|---------|---------|
| **患者搜索** | 多字段搜索 | PatientSearch.vue | `GET /doctor/patient/search?q=` | LIKE 匹配 name/student_id/phone/pinyin |
| | 新建患者 | PatientSearch.vue | `POST /doctor/patient` | 按类型校验必填字段 |
| | 更新患者 | PatientSearch.vue | `PUT /doctor/patient/<id>` | 仅可改联系方式 |
| | 患者历史 | PatientSearch.vue | `GET /doctor/patient/<id>/visits` | 按时间倒序 |
| **接诊开方** | 新建就诊 | VisitForm.vue | `POST /doctor/visits` | 诊断+最少一个用药项校验 |
| | 药品搜索 | VisitForm.vue | `GET /doctor/drugs/search?q=` | 返回库存状态 |
| | 诊断搜索 | VisitForm.vue | `GET /doctor/diagnoses/search?q=` | ICD-10编码+中文 |
| | 药物录入 | DrugEntry.vue | (本地) | 用法/用量/频次/时间/天数/数量 |
| | 补充病历 | VisitForm.vue | `PUT /doctor/visits/<id>/medical-record` | 仅 pending/rejected 可改 |
| **文本模板** | 模板列表 | TextTemplates.vue | `GET /doctor/templates?category=` | 按 3 种类别 |
| | 新建模板 | TextTemplates.vue | `POST /doctor/templates` | |
| | 编辑/删除 | TextTemplates.vue | `PUT/DELETE /doctor/templates/<id>` | |
| **挂单** | 保存挂单 | VisitForm.vue | `POST /doctor/parked-visits` | 每个患者+医生不超过一个 |
| | 挂单列表 | PatientSearch.vue | `GET /doctor/parked-visits` | |
| | 恢复挂单 | PatientSearch.vue | `GET /doctor/parked-visits/<id>` | |
| | 删除挂单 | PatientSearch.vue | `DELETE /doctor/parked-visits/<id>` | |
| **历史** | 处方历史 | PrescriptionHistory.vue | `GET /doctor/visits/history` | 分页+日期筛选 |
| | 就诊详情 | PrescriptionHistory.vue | `GET /doctor/visits/<id>` | 含状态时间线 |
| | 修改记录 | PrescriptionHistory.vue | `GET /doctor/visits/<id>/revisions` | |
| **零散用药** | 快速开药 | DirectPurchase.vue | `POST /doctor/visits` (visit_id=null) | |
| **账号** | 修改密码 | AccountSettings.vue | `POST /auth/change-password` | 新密码≥12位 |

### 3.2 护士端（Nurse）

| 功能组 | 功能 | 页面/组件 | 对接 API | 关键约束 |
|--------|------|-----------|---------|---------|
| **待处理** | 待处理列表 | PendingList.vue | `GET /nurse/pending-visits?status=` | pending/nurse_verified 两种 |
| | 处方详情 | ExecutePrescription.vue | `GET /nurse/visits/<id>` | 含库存状态 |
| **处方操作** | 审核通过 | ExecutePrescription.vue | `POST /nurse/visits/<id>/verify` | pending→nurse_verified |
| | 驳回 | ExecutePrescription.vue | `POST /nurse/visits/<id>/reject` | 必填驳回原因 |
| | 改价 | ExecutePrescription.vue | `PUT /nurse/visits/<id>/items/<iid>/modify` | 仅 nurse_verified |
| | 追加项目 | ExecutePrescription.vue | `POST /nurse/visits/<id>/service-items` | type=2/3 |
| | 修改/删除追加 | ExecutePrescription.vue | `PUT/DELETE .../service-items/<iid>` | |
| **执行收费** | 执行处方 | ExecutePrescription.vue | `POST /nurse/visits/<id>/execute` | 库存扣减+Payment生成 |
| | 职工优惠 | ExecutePrescription.vue | (execute 参数) | 分项金额需加总=total |
| | 标记已打印 | ExecutePrescription.vue | `PUT /nurse/payments/<id>/print` | |
| | 撤销 | ExecutePrescription.vue | `POST /nurse/visits/<id>/revoke` | 返还库存 |
| **入库** | 物资入库 | Inventory.vue | `POST /nurse/inbound` | purchase_price必填 |
| | 物资搜索 | Inventory.vue | `GET /nurse/drug-names/search` | 入库时检索 |
| **库存** | 库存列表 | Inventory.vue | `GET /nurse/drugs` | |
| | 普通盘点 | Inventory.vue | `POST /nurse/inventory` | |
| | 库存组盘点 | Inventory.vue | `POST /nurse/inventory/group` | |
| | 库存流水 | Inventory.vue | `GET /nurse/inventory/records` | 分页 |
| | 月报 | Inventory.vue | `GET /nurse/inventory/monthly-report` | 期初/出库/结存 |
| | 月报导出 | Inventory.vue | `GET .../export` (blob) | Excel |
| **历史** | 诊疗历史 | HistoryList.vue | `GET /nurse/my-history` | 多条件筛选 |
| | 人员列表 | HistoryList.vue | `GET /nurse/staff-list` | 下拉筛选 |
| **统计** | 营收统计 | Statistics.vue | `GET /admin/statistics/revenue` | |
| | 出库报表 | DrugOutboundReport.vue | `GET /admin/statistics/drug-outbound` | |

## 4. API → 页面对照表

| API 端点 | 调用方(页面) | 传输方向 |
|----------|------------|---------|
| `POST /auth/login` | Login.vue | → 获取token+user |
| `POST /auth/change-password` | AccountSettings.vue | → 修改密码 |
| `GET /doctor/patient/search` | PatientSearch.vue | → 搜索结果列表 |
| `POST /doctor/patient` | PatientSearch.vue | → 新建患者 |
| `PUT /doctor/patient/<id>` | PatientSearch.vue | → 更新信息 |
| `GET /doctor/drugs/search` | VisitForm.vue, DirectPurchase.vue | → 药品下拉 |
| `GET /doctor/diagnoses/search` | VisitForm.vue | → 诊断下拉 |
| `POST /doctor/visits` | VisitForm.vue, DirectPurchase.vue | → 提交就诊 |
| `GET /doctor/visits/history` | PrescriptionHistory.vue | → 历史列表 |
| `GET /doctor/visits/<id>` | PrescriptionHistory.vue | → 详情+时间线 |
| `GET /doctor/templates` | TextTemplates.vue | → 模板列表 |
| `POST/PUT/DELETE /doctor/templates` | TextTemplates.vue | → 模板CRUD |
| `POST /doctor/parked-visits` | VisitForm.vue | → 保存草稿 |
| `GET /doctor/parked-visits` | PatientSearch.vue | → 挂单列表 |
| `GET /nurse/pending-visits` | PendingList.vue | → 待处理列表 |
| `GET /nurse/visits/<id>` | ExecutePrescription.vue | → 处方详情 |
| `POST /nurse/visits/<id>/verify` | ExecutePrescription.vue | → 审核通过 |
| `POST /nurse/visits/<id>/reject` | ExecutePrescription.vue | → 驳回 |
| `POST /nurse/visits/<id>/execute` | ExecutePrescription.vue | → 执行 |
| `POST /nurse/visits/<id>/revoke` | ExecutePrescription.vue | → 撤销 |
| `PUT .../items/<id>/modify` | ExecutePrescription.vue | → 改价 |
| `POST .../service-items` | ExecutePrescription.vue | → 追加项目 |
| `POST /nurse/inbound` | Inventory.vue | → 入库 |
| `POST /nurse/inventory[/group]` | Inventory.vue | → 盘点 |
| `GET /nurse/inventory/records` | Inventory.vue | → 流水 |
| `GET /nurse/inventory/monthly-report` | Inventory.vue | → 月报 |
| `GET /admin/drugs` | DrugManagement.vue, DrugPriceView.vue | → 药品列表 |
| `POST/PUT /admin/drugs` | DrugManagement.vue | → 药品CRUD |
| `POST /admin/drugs/smart-inventory` | DrugManagement.vue | → 智能盘库 |
| `GET /admin/users` | UserManagement.vue | → 用户列表 |
| `POST/PUT/DELETE /admin/users` | UserManagement.vue | → 用户CRUD |
| `GET /admin/patients` | PatientManagement.vue | → 患者列表 |
| `GET /admin/statistics/revenue` | Statistics.vue | → 营收数据 |
| `GET /admin/statistics/drug-outbound` | DrugOutboundReport.vue | → 出库数据 |
| `GET /admin/backup` | SystemSettings.vue | → 备份下载 |
| `GET /admin/operation-logs` | OperationLog.vue | → 日志 |

### 5.3 营收统计数据流

```
GET /admin/statistics/revenue?start=YYYY-MM-DD&end=YYYY-MM-DD
                    │
                    ▼
          [查询 completed Visit + Payment]
                    │
                    ▼
          For each Visit:
            ├── allocatePaymentRevenue()
            │   ├── 归类 PrescriptionItems 原始金额(type)
            │   ├── 按比例分摊实收总额
            │   └── 处理职工优惠显式分项
            └── 计算 cost = Σ items.purchase_cost
                    │
                    ▼
          返回: [{ visit_id, patient_name(脱敏), 
                   consultation, drug, service, consumable,
                   total, cost, profit, payment_date }]
```
