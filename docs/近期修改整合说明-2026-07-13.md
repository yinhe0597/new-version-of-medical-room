## 3. 已整合能力

### 3.1 安全与运行配置

- 运行时密钥持久化、基础账号随机初始密码、12 位密码策略、账号软停用和 JWT `token_version` 失效机制。
- CORS、请求体和表格导入限制；财务数据脱敏、病例打印 XSS 防护和 CSV/Excel 公式注入防护。
- 默认使用项目根目录 `data/app.db`，外部数据库通过环境变量接入；Windows 后台启动不再受控制台编码和 EOF 影响。

### 3.2 库存、收费与业务时间

- 处方执行和撤销使用结构化库存流水，盘点、月报和整装/拆零库存统一按基础单位守恒。
- 收入统计统一通过实收分摊服务计算，管理端、财务端和导出口径一致。
- API 查询边界、数据库存储和界面/导出显示统一使用 UTC 与 `Asia/Shanghai` 转换工具，移除散落的手工 `+8/-8`。

### 3.3 数据库迁移与发布门禁

- 历史 Alembic revision 改为幂等、forward-only 接管；禁止危险 downgrade 和离线 `--sql`。
- SQLite 迁移失败整体回滚并恢复外键检查；真实旧库副本升级保持 105,122 行、全部主键、22 个历史扩展字段和既有外键悬空记录不变。
- MySQL 验收器覆盖 `fresh`、`history`、`retry`，并限制服务器、凭据来源、资源所有权和清理范围。
- 后端测试改为自动发现全部 `backend/tests/test_*.py`；Linux Release 增加后端全量测试和 Python 编译门禁。
