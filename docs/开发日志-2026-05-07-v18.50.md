# 开发日志 v26.05.07.18.50（2026-05-07）

## 本次更新概述

修复多处时间显示问题（UTC→CST时区转换）、护士端库存盘点翻页、医生端零散用药默认天数调整、库存管理流程重构（统一入库/盘点勘误到药品管理编辑页）、新增每日库存快照机制与月度盘点报表优化。

## 一、修复1：管理员端药品出库报表出库时间显示修复

### 问题现象

药品出库报表中出库时间显示的是 UTC 时间，而非中国标准时间（CST），导致时间偏差 8 小时。

### 修复方案

在 `admin.py` 中药品出库报表明细接口和导出接口，对 `payment_date` 格式化前加 `timedelta(hours=8)` 转换为中国标准时间。

```python
# 修复前
payment_date = visit.payment_date.strftime('%Y-%m-%d %H:%M')

# 修复后
payment_date = (visit.payment_date + timedelta(hours=8)).strftime('%Y-%m-%d %H:%M')
```

## 二、修复2：管理员端统计报表时间显示修复

### 问题现象

营收统计报表时间同样显示 UTC 时间而非本地时间。

### 修复方案

`admin.py` 中营收统计明细接口和导出接口的 `payment_date` 同样加 `timedelta(hours=8)` 转换。

## 三、修复3：护士端时间显示修复

### 修复方案

`nurse.py` 中库存变动记录的 `timestamp` 和收费确认的 `payment_date` 加 `timedelta(hours=8)` 转换为中国标准时间。

## 四、功能4：护士端库存盘点页面添加翻页功能

### 后端改动

`nurse.py` 中 `/nurse/drugs` 接口从 `limit(50)` 改为 `paginate()` 分页查询，支持前端传入页码和每页条数。

### 前端改动

`Inventory.vue` 添加 `el-pagination` 分页组件，支持翻页浏览库存列表。

## 五、功能5：医生端零散用药默认天数改为2天

### 改动说明

医生开处方时，勾选"零散用药"选项后天数自动设为 2 天，取消勾选则恢复默认 1 天。

## 六、功能6：库存管理流程重构

### 改动概要

- **删除护士端"入库管理"标签页**，将入库操作统一到管理员药品管理编辑页
- **药品管理编辑页新增"盘点勘误"和"入库"按钮**，方便管理员直接操作
- **新增入库接口**：`POST /admin/drugs/<id>/inbound`，支持管理员通过编辑页直接入库
- **新增 DailyStockSnapshot 数据模型**：系统每天 0 点自动保存所有药品的库存快照
- **run_prod.py 添加后台快照调度线程**：使用调度器在每日 0 点执行库存快照任务
- **月度盘点报表重构**：优先使用快照数据查询期初/期末库存，日期选择器简化为仅日期
