### 1. 医生端学生信息搜索功能异常

#### 问题描述
- 医生端搜索框无法正常搜索学生信息
- 只返回几条预置demo数据（如：张三、李四、王五）
- 无法从真实数据库（`ceshi/app.db`）中搜索14547条学生数据

#### 问题分析
1. **数据库连接问题**：
   - 后端使用了错误的数据库（`backend/app.db`）而非指定的`ceshi/app.db`
   - `config.py`中默认使用当前目录下的`app.db`
   - `run.py`中环境变量设置在`create_app()`之后，导致配置未生效

2. **API路由问题**：
   - 虽然`doctor.py`中`search_patient`函数已修改为直接连接指定数据库
   - 但存在多个Python进程同时运行，旧进程仍占用5000端口
   - 导致代码修改未生效，仍返回旧数据

#### 解决方案

##### 方案B：优化`search_patient`函数
**文件位置**：`backend/app/api/doctor.py`
**修改内容**：
- 保持直接使用sqlite3连接指定数据库的逻辑
- 确保查询完整的搜索条件：姓名、学号、电话、姓名拼音全称、姓名拼音首字母

```python
@bp.route('/doctor/patient/search', methods=['GET'])
@role_required('doctor')
def search_patient():
    import logging
    logger = logging.getLogger(__name__)
    
    start = time.perf_counter()
    keyword = request.args.get('keyword', '').strip()
    if not keyword:
        return jsonify({"msg": "Missing keyword parameter"}), 400

    kw_lower = keyword.lower()
    logger.info(f"Searching for keyword: {keyword}, kw_lower: {kw_lower}")

    user_id = get_jwt_identity()
    now_ts = time.time()
    if not hasattr(search_patient, "_rate"):
        search_patient._rate = {}
    bucket = search_patient._rate.setdefault(str(user_id), [])
    bucket[:] = [t for t in bucket if now_ts - t < 10]
    if len(bucket) >= 30:
        return jsonify({"msg": "Too many requests"}), 429
    bucket.append(now_ts)

    # 直接使用sqlite3连接指定的数据库文件
    import sqlite3
    import os
    
    db_path = os.path.abspath("E:\\yws2\\medical-room-management-system\\ceshi\\app.db")
    logger.info(f"Using database: {db_path}")
    logger.info(f"Database exists: {os.path.exists(db_path)}")
    
    conn = sqlite3.connect(db_path)
    cursor = conn.cursor()
    
    # 添加完整的搜索过滤逻辑
    query = """
        SELECT id, student_id, name, gender, class_name, phone, created_at, 
               grade, college, major, name_pinyin, name_initials, is_temporary, 
               age, id_card, counselor_name
        FROM patient 
        WHERE (name LIKE ? OR 
               student_id LIKE ? OR 
               phone LIKE ? OR 
               name_pinyin LIKE ? OR 
               name_initials LIKE ?)
        LIMIT 50
    """
    
    # 构建搜索参数
    search_params = [
        f"%{keyword}%",  # 姓名
        f"%{keyword}%",  # 学号
        f"%{keyword}%",  # 电话
        f"%{kw_lower}%",  # 拼音全称
        f"%{kw_lower}%"   # 拼音首字母
    ]
    
    logger.info(f"Executing search query with params: {search_params}")
    cursor.execute(query, search_params)
    patients = cursor.fetchall()
    logger.info(f"Found {len(patients)} patients matching keyword")
    
    conn.close()

    if not patients:
        resp = jsonify({"data": []})
        resp.headers["X-Response-Time-ms"] = f"{(time.perf_counter() - start) * 1000:.2f}"
        return resp, 200

    data = []
    for patient in patients:
        data.append({
            "id": patient[0],
            "student_id": patient[1],
            "name": patient[2],
            "gender": patient[3],
            "grade": patient[7],
            "college": patient[8],
            "major": patient[9],
            "class_name": patient[4],
            "phone": patient[5],
            "counselor_name": patient[15],
            "is_temporary": bool(patient[12]),
            "age": patient[13]
        })

    logger.info(f"Returning {len(data)} patients")
    
    resp = jsonify({"data": data})
    resp.headers["X-Response-Time-ms"] = f"{(time.perf_counter() - start) * 1000:.2f}"
    return resp, 200
```

### 2. 系统不稳定，频繁登出问题（历史问题回顾）

#### 问题描述
- 用户反映系统不稳定，使用过程中频繁被登出
- 无法长时间使用系统

#### 问题分析
- JWT令牌过期时间过短（默认15分钟）
- 前端错误处理过于激进，网络波动就清除token

#### 解决方案

##### 修改JWT过期时间
**文件位置**：`backend/config.py`
**修改内容**：
```python
# 将JWT令牌过期时间从默认的15分钟延长到7天
JWT_ACCESS_TOKEN_EXPIRES = timedelta(days=7)  # 延长令牌过期时间到7天
```

##### 优化前端错误处理
**文件位置**：`frontend/src/api/request.js`
**修改内容**：
- 只在明确的认证失败时才清除token
- 网络错误、超时等情况不触发登出

### 3. 护士端修改诊疗项目功能

#### 需求描述
护士在接收医生处方的过程中，若处方中含有"诊疗项目"，则护士有权进行"处方修改"。修改限制：
- 只能增减处方"诊疗项目"的类目和数量
- 对原有"药物处方"无权改动

#### 解决方案

##### 后端API新增
**文件位置**：`backend/app/api/nurse.py`

新增接口：
1. `POST /nurse/visits/{visit_id}/service-items` - 添加诊疗项目
2. `PUT /nurse/visits/{visit_id}/service-items/{item_id}` - 修改诊疗项目数量
3. `DELETE /nurse/visits/{visit_id}/service-items/{item_id}` - 删除诊疗项目
4. `GET /nurse/services/search` - 搜索可用的诊疗项目

**权限控制**：
- 只允许护士在处方"已审核待执行"状态时修改
- 结算完成后禁止修改
- 只能操作type=2的项目（诊疗项目）

##### 前端界面优化
**文件位置**：`frontend/src/views/nurse/ExecutePrescription.vue`

新增功能：
- 诊疗项目管理卡片，独立于药物处方
- 添加诊疗项目按钮，调用搜索和添加API
- 数量编辑功能
- 删除确认按钮
