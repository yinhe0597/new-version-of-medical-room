# 更新日志 V2.0.0

发布日期：2026-04-21

## 医生端
- 接诊前二次确认：开始接诊/保存并接诊前弹窗确认患者基本信息，确认后才进入接诊页。
- 模板管理：新增主诉模板、体格检查模板、医生贴士模板的管理入口（按医生账号隔离）。
- 模板快捷填入：在接诊页主诉/体格检查/医生贴士输入框末尾输入 `##`，弹出模板选择并一键插入。
- 诊查费默认值：接诊页默认诊查费调整为 8 元。
- 用量下拉补全：计数类单位（片/粒/袋/包/支/瓶/贴/喷/丸/次/滴等）补全到 6；ml/g 等单位不做扩展。
- 重新开方闭环：医生历史就诊记录中，若处方被护士驳回（rejected），支持“重新开方”快速载入原处方草稿并重新提交给护士审核。

## 后端
- 新增常用文本模板数据模型与接口：
  - `GET /api/doctor/templates`
  - `POST /api/doctor/templates`
  - `PUT /api/doctor/templates/<id>`
  - `DELETE /api/doctor/templates/<id>`
- 就诊历史与详情接口补充字段，支持医生端“重新开方”草稿载入：
  - `GET /api/doctor/visits/history` 增加 `patient_id`、`student_id`
  - `GET /api/doctor/visits/<visit_id>` 的 `items` 增加 `drug_id`、`drug_type`、`price_at_visit`
