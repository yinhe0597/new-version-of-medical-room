# 开发日志 open0.0.4

## 更新日期
2026-05-11

## 版本
open0.0.4

## 本次更新内容

### 一、安全加固 - 文件上传防护

#### 功能概述
对系统中所有文件上传端点增加安全校验：统一 10MB 大小限制，Excel 导入端点补充扩展名白名单，防止恶意大文件上传和任意文件类型上传。

#### 后端改动

**`backend/app/api/admin.py`**
- 新增 `MAX_UPLOAD_SIZE = 10MB` 常量和 `_check_upload_size()` 辅助函数，通过 `seek(0, 2)` + `tell()` 检测实际文件大小（不可被 Content-Length 头伪造）
- `/admin/patients/import`（CSV 导入）：新增大小校验
- `/admin/drugs/import`（CSV 导入）：新增大小校验
- `/admin/drugs/import_xls`（Excel 导入）：新增 `.xls/.xlsx` 扩展名白名单 + 大小校验

---

### 二、人员档案管理 - 完整 CRUD 体系

#### 功能概述
管理员端"人员档案管理"页面从仅有批量 CSV 导入，升级为完整的人员管理体系：支持分页列表、关键词搜索、单个新增、编辑、删除、批量导入。支持学生、教职工、临时人员三类身份，与医生端数据完全互通。

#### 后端改动

**`backend/app/api/admin.py`（新增 4 个端点）**
- `GET /admin/patients`：分页查询人员列表，支持姓名/学号/拼音/手机号模糊搜索
- `POST /admin/patients`：单个新增人员，自动计算拼音索引，学号唯一性校验，记录运营日志
- `PUT /admin/patients/<id>`：编辑人员信息，学号变更时校验唯一性，姓名变更时同步更新拼音索引
- `DELETE /admin/patients/<id>`：删除人员（有就诊记录的不允许删除）

#### 前端改动

**`frontend/src/views/admin/PatientManagement.vue`（完全重写）**
- 新增人员列表表格：学号、姓名、性别、年龄、学院、专业、班级、手机号、辅导员、类型（正式/临时）
- 搜索栏：支持姓名/学号/拼音/手机号搜索，回车或点击按钮触发
- 分页组件：支持 20/50/100 条切换
- 新增/编辑弹窗：完整表单含所有字段，支持切换"正式人员"/"临时人员"类型
- 删除：二次确认，有就诊记录的提示无法删除
- 批量导入：保留原有 CSV 导入功能，移入独立弹窗

**`frontend/src/views/admin/Dashboard.vue`**
- 侧边栏菜单"学生档案管理"更名为"人员档案管理"

#### 数据互通
- 管理员新增/导入的人员，医生端拼音/姓名/学号搜索均可找到
- 医生端创建的临时患者，管理员端列表中可见并可管理
- `is_temporary` 字段区分正式人员和临时人员

### 三、就诊历史查看 - 医生端 + 管理员端

#### 功能概述
补全就诊历史查看入口：医生搜索患者后可直接查看该患者的历史就诊记录和病历详情；管理员在人员档案管理中可查看任意人员的完整就诊历史。

#### 后端改动

**`backend/app/api/admin.py`（新增 2 个端点）**
- `GET /admin/patients/<id>/visits`：获取指定患者的就诊历史列表（时间、接诊医生、主诉、诊断、金额、状态）
- `GET /admin/visits/<visit_id>`：获取单次就诊完整详情（患者信息、电子病历、处方明细）

**`backend/app/api/doctor.py`（修复 2 个字段缺失）**
- `GET /doctor/patient/<id>/visits`：补充 `status` 和 `chief_complaint` 字段到响应
- `GET /doctor/visits/<visit_id>`：补充 `doctor_name` 字段到响应

#### 前端改动

**`frontend/src/views/doctor/PatientSearch.vue`**
- 患者信息卡片新增"查看就诊历史"按钮
- 点击展开该患者的历史就诊列表（时间、诊断、金额、状态）
- 点击"详情"弹出完整病历：患者信息、主诉、现病史、既往史、体格检查、诊断、医生留言、处方明细
- 选中不同患者时自动重置历史状态

**`frontend/src/views/admin/PatientManagement.vue`**
- 表格操作列新增"病历"按钮
- 点击弹出该人员的就诊历史列表（时间、接诊医生、主诉、诊断、金额、状态）
- 点击"详情"弹出完整就诊详情（同医生端病历复盘视图）

### 三、单独购药 - 用量下拉选项对齐接诊开方

#### 功能概述
"单独购药"界面的用法用量下拉选项少于"接诊开方"界面（缺半单位、多数计数单位、液体/固体体积重量选项），导致医生在单独购药时无法选择合适的用量。本次修改将 `buildDosageOptions()` 函数补齐为与 `VisitForm.vue` 完全一致的选项集。

#### 后端改动
无

#### 前端改动

**`frontend/src/views/doctor/DirectPurchase.vue`**
- 重写 `buildDosageOptions()` 函数，补齐以下用量选项：
  - 半单位：半片、半粒、半袋、半包
  - 计数单位 1-6：片、粒、袋、包、支、瓶、贴、喷、丸、次、滴
  - 液体体积：1ml、2ml、5ml、10ml、20ml、50ml、100ml
  - 固体重量：0.5g、1g、2g、5g、10g、15g、20g
  - 适量
- 不改动模板 UI 结构，不添加自动计算功能
