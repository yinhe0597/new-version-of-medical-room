## ✨ 项目简介

本项目是一套面向高校/中小学医务室场景的**全栈诊疗与药品/耗材管理系统**，覆盖"接诊开方 → 护士审核 → 发药结算 → 库存与营收统计"的完整业务闭环。

系统采用 **医生 / 护士 / 管理员** 三端独立界面设计，各角色权限边界清晰，操作流程贴合真实校医务室工作场景。无论是日常接诊高峰期的快速开方，还是月末库存盘点与营收报表，都能高效完成。

### 🌟 核心优势

- 🔄 **全流程闭环**：从患者挂号到处方结算，每一步都有系统支撑
- 🎒 **三类物资管理**：药品 + 诊疗项目 + 耗材，统一管理但各行其道
- 🔒 **安全兜底**：处方提交与审核均有后端强校验，杜绝绕过业务规则
- 💊 **库存实用**：支持"整包装 + 拆零"联动入库与扣减，适配真实发药场景
- 🏗️ **角色清晰**：Admin / Doctor / Nurse 按职责拆分能力与接口
- 🚀 **易部署**：SQLite 零配置启动，PyInstaller 打包开箱即用
- 🔄 **平滑升级**：自动检测并补全旧数据库缺失字段和表，无感迁移
- 📊 **数据洞察**：营收统计（药品/诊疗/耗材三路拆分）、药品消耗、医生工作量多维报表

## 🚀 快速开始

### 方式一：直接运行（推荐）

```
1. 下载最新 Release 包
2. 将数据库文件 app.db 放入 data/ 目录
3. 双击 启动系统.bat
4. 浏览器访问 http://localhost:5000
```

### 方式二：源码开发

**后端 (Python 3.8+)**
```bash
cd backend
python -m venv .venv
# 激活虚拟环境 (Windows: .venv\Scripts\activate | Linux/Mac: source .venv/bin/activate)
pip install -r requirements.txt

# 初始化数据库结构与基础账号
python init_db.py

# (可选) 导入 ICD-10 疾病字典数据
python import_icd10.py

# 启动开发服务器
python run.py
```

**前端 (Node.js 18+)**
```bash
cd frontend
npm install
npm run dev
```

## 📝 V2.0.0 关键用法速记（医生端）

- **模板快捷填入**：在接诊页"主诉/体格检查/医生贴士"输入框末尾输入 `##`，弹出模板列表，点选即可插入。
