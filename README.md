# 校医务室诊疗管理系统 (CMIS)

## 📖 项目简介

本系统是专为校医务室定制开发的轻量级 B/S 架构诊疗管理系统。旨在解决传统纸质病历查找困难、手工记账繁琐、药品库存管理混乱等痛点，实现电子病历书写、处方流转、药品进销存以及财务结算的全流程数字化闭环管理。

**版本**: V1.08
**架构**: 前后端分离 (Vue 3 + Flask + SQLite)
**部署方式**: 支持单机/局域网服务器一键部署

## ✨ 核心功能模块

### 1. 👨‍⚕️ 医生工作站

专为医生接诊设计，提供流畅的看诊开药体验：

- **患者管理**：支持通过学号/工号快速检索患者；未检索到时**自动切换至无缝建档流程**。
- **电子病历**：结构化录入主诉、现病史、既往史（过敏史）、体格检查及诊断结果。
- **智能处方**：
  - 支持关键词模糊搜索药品，实时显示剩余库存。
  - 详细录入药品用法、用量、频次、\*\*服药时间（如餐前、餐后）\*\*及天数。
  - 系统自动计算药品总价及自定义诊察费。
  - 支持为患者添加\*\*“医生留言/小贴士”\*\*（如：多喝水、忌辛辣）。
- **病例复盘**：可追溯历史就诊记录，支持一键打开“病例复盘”弹窗，查看历史病历详情及处方明细。

### 2. 👩‍⚕️ 护士工作站

专注处方执行与财务结算，保障药品出库安全：

- **待处置大厅**：实时获取医生开具的待处理处方列表。
- **智能抓药结算**：
  - 结算前自动进行二次库存校验，库存不足时醒目预警。
  - 支持选择多种支付方式登记（现金、一卡通等）。
  - 结算完成即自动扣减对应药品库存，生成财务流水。
- **票据打印**：提供结构化的收费票据打印，**票据内直观展示药品详细用法及“医生小贴士”**，方便患者遵医嘱用药。
- **实时库存**：提供快捷的只读药品库存查询功能。

### 3. ⚙️ 管理员后台

掌控全局数据，维护系统基础字典：

- **药品字典维护**：支持药品的增、删、改、查及停用/启用管理。
- **批量入库**：支持下载标准 CSV 模板，**一键批量导入/更新药品库存**（支持多编码格式解析，自动去重累加）。
- **财务报表**：提供日、月、年维度的营收数据可视化报表，区分诊察费与药品收入。
- **数据安全**：提供一键数据库备份功能，保障核心数据不丢失。

## 🚀 快速开始 (开发环境)

### 前置要求

- Node.js 16+
- Python 3.8+

### 1. 一键启动 (Windows)

双击运行项目根目录下的 `start_dev.bat` 即可同时启动前后端服务。

### 2. 手动启动

**启动后端 (端口: 5000)**

```bash
cd backend
# 建议创建并激活虚拟环境
pip install -r requirements.txt
python init_db.py  # 首次运行初始化数据库及测试数据
python run.py
```

**启动前端 (端口: 5888)**

```bash
cd frontend
npm install
npm run dev
```

### 3. 访问系统

打开浏览器访问: `http://localhost:5888`

**预设测试账号 (密码均为** **`123456`)**:

- 管理员: `admin`
- 医生: `doctor`
- 护士: `nurse`

## 📦 部署建议 (Windows Server)

1. **后端**：安装 Python 环境，推荐使用 `waitress` 作为 WSGI 服务器运行 Flask 应用 (`waitress-serve --port=5000 --call run:create_app`)。
2. **前端**：在开发机执行 `npm run build`，将生成的 `dist` 目录使用 Nginx 或 IIS 托管，并配置 `/api` 代理转发至后端 5000 端口。
3. **数据**：本系统使用 SQLite（`backend/app.db`）进行数据存储，建议定期执行数据库备份并妥善保存。
