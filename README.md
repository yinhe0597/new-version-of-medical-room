# 校医务室诊疗管理系统 (Medical Room Management System)

本项目为一套专为学校医务室设计的全栈诊疗与库存管理系统。支持医生开方（结合 ICD-10 诊断库）、护士处方审核与改价、药品进销存、学生批量导入以及管理员营收统计等核心功能。

数据库支持 SQLite 与 MySQL（通过环境变量配置连接），后端使用 Flask (Python) 提供 API 服务，前端基于 Vue 3 + Element Plus 构建。

## 更新日志

### V1.10（2026-04-13）

- 医生端：处方提交后端强制校验（diagnosis、items 非空；药品明细用法/用量/频次/时间必填；数量与天数合法性；库存校验不可绕过）
- 护士端：审核（verify）阶段增加处方完整性与库存可执行性校验，避免“只改状态不审核”；执行结算仍强制要求已审核
- 库存入库：新增“整包装 + 拆零”同批次联动入库与扣减机制，医生端可按“药品A/药品A(散)”两行选择
- 护士端功能下放：护士可使用药品管理全量能力（CRUD/导入/模板/智能盘库），并新增护士端入口页面
- 报表：营收统计新增 Excel 导出接口与前端下载按钮，护士端同样可导出
- 测试：补齐后端关键路径单元测试（处方强校验、护士审核校验），并补充入库/拆零相关测试与测试报告

## 项目基础命令速查

**后端 (Python 3.8+ / MySQL 5.7+)**
```bash
cd backend
python -m venv .venv
# 激活虚拟环境 (Windows: .venv\Scripts\activate | Linux/Mac: source .venv/bin/activate)
pip install -r requirements.txt

# 初始化数据库结构与基础账号
python init_db.py

# (可选) 导入 ICD-10 疾病字典数据
python import_icd10.py

# 启动开发服务器
python run.py
```

**前端 (Node.js 18+)**
```bash
cd frontend
npm install
npm run dev
```

*（注：更详细的环境要求和 MySQL 前置操作请务必参考 `部署与维护说明.md`。）*
